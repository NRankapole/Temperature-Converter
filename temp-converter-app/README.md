# 📗 Temperature Converter & Team Directory

## Overview

This is react application used to automatically convert the value of tempreature from celsius to fahrenheit and visa versa. It is also used to filter through a list of employee details by name.

It includes two main features:

1. **Temperature Converter**  
   - Convert between Celsius and Fahrenheit  
   - The inputs are synchronized so they both update automatically  

2. **Team Directory**  
   - Filter a list of employees by name  
   - Table display using DaisyUI  
 

---
## ⚙️ Features & Functionality

### Temperature Converter
- Two input fields (`Celsius` and `Fahrenheit`)  
- Inputs are **controlled** and **synchronized**  
- Temperature is stored as a **single source of truth**  
- Background color changes can be added dynamically based on temperature (planned)  
---

### Team Directory
- Displays **20 hardcoded employees** in a **DaisyUI table**  
- Search/filter by name in real time  
- List is **derived** from search query — no redundant state  
- Clean, modern card layout
